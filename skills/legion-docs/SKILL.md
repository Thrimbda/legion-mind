# legion-docs

创建面向工程读者、可独立理解的文档。先服从仓库现有文档约定和用户指定格式。

## 原则

- 结论和读者需要做的决定靠前；
- 事实、推断、假设、建议和未验证内容明确分开；
- 解释会改变实现或风险的取舍，不复制已有正文；
- 关键结论链接到可重查的代码、命令结果或来源；
- 只记录后续仍有使用价值的信息；
- 对敏感内容、外部承诺和实际运行状态保持准确边界。

## 工作方式

先确定读者、用途、当前真源和目标路径，再选择最小有用结构。可以整理 RFC、运行手册、验证记录、决策说明、迁移指南或普通技术说明，但不自动创建 `plan.md`、`log.md`、`tasks.md`、状态板或 Wiki。

需要更具体的写作检查时读取 `references/REF_BEST_PRACTICES.md`。
