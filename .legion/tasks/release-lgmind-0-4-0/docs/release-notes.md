# `lgmind` 0.4.0 发布说明

## 本次交付

`0.4.0` 将当前 `master` 已有的工作流与报告资产正式纳入 npm 发布包，便于其他机器通过固定版本或 `latest` 安装。版本准备本身不新增或重设计 CLI、安装器、schema、协议、agent 与报告行为。

- **注意力交接**：保留 RFC、不同 agent 分工、review 循环与最终验收的大循环，同时把阶段结论、关键风险、待人类关注项和证据入口整理为更短的人类交接，减少必须自行翻找任务目录的负担。
- **认知验证**：允许按主张的可验证性记录当前结论，明确区分已经验证、当前证据不足而无法收口以及延期验证等状态；缺少合适领域 verifier 时如实暴露证据缺口和后续验证条件，不伪造确定性。
- **报告一致性**：报告数据、固定 Verdict 与底层 test、review、verification 证据之间增加一致性校验，避免顶层显示 `PASS` 而底层存在 `FAIL` 或 `BLOCKED`；同一份 `report-data.json` 可确定性生成 HTML、Markdown 与 PR body。
- **安装资产**：发布包携带当前主干中的注意力协议、认知验证协议、报告 schema/template、Verdict 解析与报告数据校验脚本、subagent 命名器和 context manifest 等安装所需资产。

## 边界

- 本次发布交付的是已经合并到 `master` 的能力，不把尚未执行的完整多任务、多模型 A/B 视为已经证明。
- npm 发布、registry 状态与干净环境安装结果需在后续发布阶段单独验证；本说明不替代这些证据。
- scheduler 是独立包，本次不修改其版本。
