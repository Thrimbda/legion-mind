风险与限制

风险缓解
Unicode 字符数是 tokenizer 无关代理指标，不是任一模型的精确 token 数。报告同时保留固定基线、绝对值、预算和百分比，不把字符数冒充 token。
强制 reference 扫描是依赖现行措辞与 locator 形式的词法启发式。当前已知 reference 全部进入 manifest；新增强制加载时必须同步清单并重跑审计。
报告事务证明进程内异常恢复，不覆盖进程强杀、断电或未来 Markdown 方言。固定反例持续守住当前消费者；运行时或渲染语义变化后重新验证。
