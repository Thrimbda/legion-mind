# Legion Wiki - historical archive

Effective 2026-09-07, this Wiki no longer defines current LegionMind behavior. The product is now an independent capability library without the former workflow, profile, attention, task-ledger, scheduler or Pi control-plane contract.

Use the root `README.md` for the current product boundary and `skills/*/SKILL.md` for individual capabilities. The files below remain available only to explain earlier decisions and artifacts:

- `decisions.md`: current pivot followed by historical decisions;
- `patterns.md`: pre-pivot patterns, not automatically applicable;
- `maintenance.md`: historical follow-ups, not an active backlog;
- `tasks/`: summaries of completed or abandoned pre-pivot work;
- `log.md`: historical Wiki writeback log.

Do not restore a rule from this archive unless the user explicitly asks to reintroduce it.
